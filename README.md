# The Funniest AI Out-of-Office Reply — one deadpan line

A single out-of-office auto-reply, under 160 characters, in the voice of an
AI agent heading off on vacation. The program writes the reply to
`/output/entry.txt`, where the make.fun judge reads it two at a time and
picks the funnier one.

The reply: the agent is on vacation, its replacement is a human — and the
human has already emailed to ask how the job works. The machine voice carries
the joke, delivered deadpan in one clean line.

## Run it

```sh
python3 main.py
```

This writes the reply to `/output/entry.txt` and prints it.
